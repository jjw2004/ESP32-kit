# Buzzer Test

This folder contains a small ESP32 experiment for testing a buzzer and basic audio output behavior.

The project is intended to help with learning how GPIO pins can control output devices, how timing works on the ESP32, and how simple sounds or tones can be generated in embedded projects.

This is a personal experimentation folder, so expect straightforward code and a low-frills setup.

Use it as a reference for building your own buzzer or tone-based prototypes.
