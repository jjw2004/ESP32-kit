# Big Password

This folder contains the ESP32 project files for the big-password experiment.

The code here is intended as a small hardware and software playground for trying out password-related input ideas, testing wiring, and learning how the ESP32 behaves with different components.

This is a personal tinkering project, so the structure may be simple and the code may change as ideas evolve.

Feel free to use this as a reference or starting point for your own work.
