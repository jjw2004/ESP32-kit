# RFID Sensor

This folder contains the ESP32 code for experimenting with RFID sensing and tag reading.

The goal of this project is to learn how the ESP32 can interface with RFID hardware, read card or tag data, and use that information in a simple embedded application.

This is a hands-on learning project aimed at experimentation and rapid prototyping.

Use this folder as a reference for RFID projects, access control ideas, or other sensor-based experiments.
