# Membrane Keypad

This folder contains the ESP32 project files for experimenting with a membrane keypad.

The goal is to learn how input devices can be read by the ESP32, how key events are interpreted, and how to build simple user input interfaces for prototypes or control panels.

This project is intentionally simple and practical, making it useful for learning and quick testing.

Use this folder as a base for keypad-driven projects, menu systems, or hardware input experiments.
