# IR Relay

This folder contains the ESP32 code for experimenting with infrared-controlled relay behavior.

The goal of this project is to explore how an IR signal can trigger a relay output, making it useful for simple remote-controlled switching or automation experiments.

This is a hands-on learning project, so the examples are meant to be easy to understand and adapt for your own custom hardware setup.

Use this as a starting point for relay control, remote automation, and prototype electronics testing.
