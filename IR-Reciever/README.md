# IR Receiver

This folder contains the ESP32 code for experimenting with an infrared receiver.

The goal of this project is to learn how IR signals are received and decoded, and how an ESP32 can interact with remote-control based inputs.

This is a simple tinkering project meant to help explore sensor input, signal decoding, and low-level device communication.

Use this as a basic reference for IR-based projects or as a starting point for your own remote-control experiments.
