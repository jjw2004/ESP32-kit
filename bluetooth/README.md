# Bluetooth

This folder contains the ESP32 Bluetooth experiments and examples in this kit.

The code here is meant for learning how ESP32 devices communicate over Bluetooth, testing connections, and exploring simple wireless prototypes.

These projects are primarily for experimentation and learning, so expect them to be lightweight, practical, and easy to adapt for your own setup.

Use this folder as a starting point for Bluetooth testing, prototyping, or custom project ideas.
